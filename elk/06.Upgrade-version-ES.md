### Bước 1: Disable replicate shard allocate
Chạy cái này thì tính năng replicate shard sẽ không hoạt động tạm thời, giảm tải I/O
```
PUT _cluster/settings
{
  "persistent": {
    "cluster.routing.allocation.enable": "primaries"
  }
}
```

### Bước 2 Flush
```
POST /_flush
```
Chức năng

•  Ghi lại và đồng bộ hóa dữ liệu trong bộ nhớ cache vào storage (như ổ cứng): Khi thực hiện các thao tác ghi (index, update, delete) trên Elasticsearch, dữ liệu sẽ được lưu trữ tạm thời trong bộ nhớ cache của Elasticsearch trước khi được ghi vĩnh viễn vào storage. Câu lệnh POST /_flush sẽ kích hoạt quá trình này, đảm bảo rằng tất cả dữ liệu trong bộ nhớ cache được ghi vào storage một cách an toàn.

•  Giải phóng bộ nhớ cache: Sau khi ghi dữ liệu, câu lệnh POST /_flush sẽ giải phóng bộ nhớ cache, giúp Elasticsearch giữ không gian bộ nhớ trống để có thể xử lý các yêu cầu tiếp theo một cách hiệu quả hơn.

•  Đồng bộ hóa dữ liệu: Quá trình flush không chỉ ghi dữ liệu từ bộ nhớ cache vào storage, mà còn đảm bảo rằng dữ liệu được đồng bộ hóa giữa các shard và các node trong cluster.

### Bước 3: Thực hiện upgrade/ rolling restart
```
Systemctl restart elasticsearch
```
### Bước 4: tắt chế độ chỉ primary, để về tất cả

```
    "cluster.routing.allocation.enable": null
  }

```
